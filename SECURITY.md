# Report a security vulnerability

Use GitHub's **Security → Report a vulnerability** private reporting flow when
available. If it is unavailable, open an issue requesting a private contact
without disclosing vulnerability details. Wait for a private route before
sending sensitive information.

Include the affected version, a minimal reproduction, relevant configuration
with secrets removed, and the security boundary involved. Do not put exploit
details, credentials, private policies, or sensitive logs in public issues.
Coordinate disclosure while the maintainers investigate and prepare a fix.
