# Participate respectfully

This project welcomes people with different backgrounds and experience.
Discuss ideas and code with evidence, explain unfamiliar terms, and respect
other people's time. Critique a proposal without attacking its author.

Harassment, threats, discriminatory abuse, sexual harassment, impersonation,
and publishing another person's private information are unacceptable in the
project's issues, pull requests, discussions, and other maintained spaces.

Report visible abuse with the host's report-content function when available.
For project moderation, open a minimal issue asking the repository maintainers
for a private conduct-reporting route. Do not include sensitive details or
identify the affected person publicly; wait for the private route before
sending those details. Maintainers may remove abusive content, warn or restrict
participants, or close a discussion. A report involving a maintainer can be
escalated through the hosting provider's abuse-reporting process.

This project does not publish an unverified email address or promise a response
deadline. Before launching a new public home, maintainers must test its issue
and moderation reporting routes as described in the launch checklist.
